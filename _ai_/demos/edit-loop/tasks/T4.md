# T4: add a case to a switch

Module: `testdata/task4` (package `palette`, file `palette.go`)

The `findKind` enum has a `findTag` value but the switch in `kindName()`
doesn't handle it, so it falls through to the default `return ""`. Add a
`case findTag:` to the switch that returns `"tag"`, in the same style as the
other cases. Do not change any other case.

Build and vet must still pass on the module afterward.
