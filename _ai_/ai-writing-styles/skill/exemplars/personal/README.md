# personal/

Writing samples that are actually Kyle's, reviewed for privacy before landing here.
Populated by `voice-cli import {imessage,mail}` (any candidate) and
`voice-cli import linear` (candidates where the author is Kyle).

Each file here should be short and human-scannable, not a raw JSON dump — the import
pipeline's job is to transform reviewed `.jsonl` candidates into readable exemplar files,
grouped by context (e.g. `pylon-style-replies.md`, `linear-tickets.md`, `short-messages.md`).
