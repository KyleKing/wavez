# Corrections log

Every time an AI draft gets hand-edited before it ships (a Pylon reply, a Linear ticket, a
PR description), append an entry here. This is the raw material for improving `SKILL.md`
and for growing `exemplars/` over time — don't skip logging something because it seems
minor, small recurring edits are the highest-signal ones.

## Format

```
## YYYY-MM-DD — context (pylon reply | linear ticket | pr description | other)

**Draft:**
> the AI-generated text, verbatim

**Edited to:**
> what it became after the human edit, verbatim

**Why (if known):** one line on what was wrong with the draft — too generic, wrong
structure, a specific banned phrase slipped through, wrong level of detail, etc.
```

## Folding corrections back into SKILL.md

When 2-3 entries here point at the same recurring problem (e.g. repeatedly stripping a
closing "let me know if that helps"), promote it: add or tighten a rule in SKILL.md's
"Hard rules" section, then note here that it was folded in (don't delete the original
entries, they're useful history of why the rule exists).
